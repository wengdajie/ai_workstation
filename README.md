# AI 工作台 · AI Workbench

面向电商与 POD 的 Windows 桌面工作台，把商品图片、视频分镜、批量图像处理和定制套图放在同一个软件中。

本仓库提供安装包、累计更新包、本地模型资源和使用文档。

## 安装与更新

支持 Windows 10（19041 及以上）/ Windows 11，x64 架构。

**首次使用**：下载安装最近的 `AIWorkbench_Setup_…_x64.exe` 完整安装包，再运行最新版本的 `AIWorkbench_Update_…_x64.exe`（如有更新）。在首页选择自动存图目录、填写主接口 API Key，并激活软件。

**已有用户**：在首页展开“软件更新与模型资源”，检查更新、下载并运行累计更新包。也可手动从最新 Release 下载 Update 文件，安装到原软件目录。更新前保存当前工作并关闭软件。

小版本仅发布累计更新包，包含发生变化的程序文件，不重复打包未改变的运行环境和本地模型。文件名中的 `from_2026.10.25` 表示最低安装基础：已安装 2026.10.25、2026.10.26 或之后兼容版本的用户可以直接安装最新累计包，不必逐个补装历史更新。更新程序会检查基础文件完整性；Update 文件不能独立安装到空文件夹。

首次安装需要完整包；更新后的软件仍需要有效授权和所用接口的 API Key。软件授权与模型服务消耗是分别管理的。

## 商品视觉工作台

### 1. 整理产品简报

上传同一商品的参考图，填写真实商品描述与销售包含物。选择制作类型与平台，设置商品类别、构图、光线、文案模式和语言；需要时补充品牌、人群及风格参考。

方案数量可设为 **1–10 张**。先选数量，再分析商品：AI 会提供三个视觉方向，每个方向包含对应数量的构图方案。也可使用本地方案，它不调用 AI 图像分析。

平台要求会进入生成提示。例如 Amazon 主图使用白底商品展示约束，不添加促销文字或无关道具。生成结果仍需自行核对商品真实性、文字和平台要求。

### 2. 在白板批量生成

选择视觉方向，勾选需要制作的图片，点击“生成所选未完成”。软件按队列生成这些方案，已有成图不会被批量按钮重复生成。

- 拖动卡片标题调整位置，拖动白板空白处平移。
- 使用滚轮或缩放按钮调整视图；“适应画布”查看全部，“自动排列”恢复规整布局。
- 右侧显示当前图片的用途、构图方案和编辑操作；也可切换列表视图。
- 草稿会保存参考图、方案、结果、历史版本、白板位置与缩放状态。
- 修改产品简报后，先重新分析或使用本地方案，再生成，避免沿用过时的商品描述。

### 3. 单图与局部编辑

**单图编辑**：选中一张成图，使用预设或输入修改要求，确认后生成修改版。原图进入历史版本，可对比或恢复。

**框选局部修改**：在图像内拖动矩形选区，或填写百分比坐标，再描述修改要求。软件请求生成候选图后，仅把选区内的结果合成回原图，选区外保留原图像素。当前是手动矩形选区，不是自动物体分割或可编辑图层；边缘衔接与选区内效果需预览确认。

每图最多保留最近 8 个历史版本。局部合成失败时可重试合成，不重新提交已成功的生图任务。任务提交结果不明确时，先继续查询或核对平台任务记录，避免重复付费生成。

成图自动保存到所选目录；保存失败会显示提示，可手动保存。勾选成图后，可通过“所选成图转视频”继续制作视频。

## 视频工作台

1. **产品简报**：上传产品参考，选择投放平台、市场、语言与视频风格。支持模特展示、单品展示、生活化展示、达人带货等方向，并包含抖音风格支持。有出镜人物时，可明确选择人物外观、性别呈现、年龄和固定细节，跨镜头沿用。
2. **参考视频分析**：上传参考视频，提取代表帧并分析镜头顺序、画面内容、字幕与可能的运镜，整理可编辑脚本。当前分析以抽帧为依据，不等于完整逐帧理解或音轨转写；快速切镜、对白与推测内容需要核实。
3. **分镜制作**：先分析商品，再检查和编辑分镜中的场景、运镜、口播、字幕与图片提示。生成分镜图并保存到本地；失败的保存操作可单独补存。
4. **视频生成**：选择可用的视频模型、比例和时长，按镜头生成视频。界面选项会根据模型能力调整，未完成任务保留 ID 供继续查询。
5. **时间线与导出**：整理镜头顺序与参数，预览素材，使用内置视频处理能力导出成片。项目可导入、导出，并有本地草稿保存。

## 自定义接口与模型

首页点击“自定义接口”，选择服务商预设，再填写自己的 API Key。内置 OpenAI、DeepSeek、硅基流动、阿里云百炼、火山方舟、Moonshot / Kimi、智谱、OpenRouter、Google Gemini、Anthropic 等预设，也可自行填写兼容接口地址。

支持模型列表同步与自动更新，也可手动添加模型 ID 并设置用途。模型会出现在适用的功能下拉列表中；已提交任务会保留所属服务商信息，继续查询时使用对应接口。

可添加接口提供的模型 ID，但能否执行文字、图片或视频任务，取决于该模型能力和接口协议。列表可见不代表具备所有生成能力；不兼容的专用协议仍需对应适配。密钥在 Windows 本地加密保存，不会随 GitHub 更新上传。

## 自主换绑

在**原绑定设备**打开首页的“自主换绑”，确认解除绑定。解绑成功后，本机退出授权，再到新设备输入同一激活码即可激活。

- 换绑前请保管好激活码。软件不会在界面显示已保存的完整卡密。
- “退出本机”仅清除本地授权信息，不解除服务器上的设备绑定。
- 换绑次数、冷却时间与是否允许解绑以授权服务返回为准；软件不能绕过服务端限制。
- 网络异常时，软件停止本机心跳并提示结果未确认，避免自动重新绑定；可输入激活码重试换绑，或到目标设备尝试激活。
- 原设备已不可用或服务端拒绝自主解绑时，需要联系授权提供方处理。

## 本地模型

模型资源在独立 Release 中，按目录分为 `models-birefnet.zip`、`models-RMBG-2.0.zip`、`models-Upscayl.zip`。将需要的压缩包解压到同一父目录，得到对应的 `models` 子目录，避免多套一层 `models/models`。

推荐放在 `D:\models`，并在对应工具中选择实际模型位置。本地抠图和高清优化依赖相应模型文件；常规软件小版本更新不要求重新下载这些文件。处理速度和可用尺寸受显存、内存与硬件影响。

## 常见问题

**生成成功但没有保存到文件夹？** 先检查首页自动存图目录和写入权限，查看该图片或镜头的保存提示，再执行单独保存。已有成图不需要重新生成。

**任务超时或提示提交结果待核对？** 超时不一定表示平台没有创建任务。保留当前项目，继续查询已保存的任务 ID；没有 ID 时先核对服务商记录，再决定是否重新生成。

**更新提示基础文件缺失？** 确认选择原安装目录。空目录或损坏安装无法使用累计更新包，可先用完整安装包修复，再更新。

**如何反馈问题？** 在 Issues 描述功能、操作步骤、软件版本和错误提示。可附不含个人信息的截图，请勿粘贴 API Key 或激活码。
